HTTP API Reference

کنترل و مانیتورینگ Xray از طریق REST/JSON — همان قابلیت‌های CLI با امکان تست زنده در /docs.

Configuration

Add an httpapi block to your Xray config:

{
  "httpapi": {
    "listen": "127.0.0.1:8080",
    "username": "admin",
    "password": "strong-password"
  }
}
FieldTypeDescription
listenstringBind address (e.g. 127.0.0.1:8080)
usernamestringOptional. Basic auth username
passwordstringOptional. Auth enabled only when both are non-empty

On start: HTTP API listening on 127.0.0.1:8080. Failed auth → 401 with {"error":"unauthorized"}.

Conventions

  • Responses: Content-Type: application/json
  • Success: HTTP 200 unless noted
  • Errors: {"error":"description"} with 400, 404, or 500
  • Wrong method → 405 Method Not Allowed

PHP Example Client

final class XrayAPI
{
    public function __construct(
        private string $baseUrl = 'http://127.0.0.1:8080',
        private string $username = 'admin',
        private string $password = 'strong-password',
    ) {}

    private function request(string $method, string $path, array $fields = [], array $headers = []): array
    {
        $url = rtrim($this->baseUrl, '/') . $path;
        $ch  = curl_init($url);
        $opts = [
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_HTTPAUTH       => CURLAUTH_BASIC,
            CURLOPT_USERPWD        => $this->username . ':' . $this->password,
            CURLOPT_CUSTOMREQUEST  => $method,
        ];
        if ($fields !== []) $opts[CURLOPT_POSTFIELDS] = $fields;
        if ($headers !== []) $opts[CURLOPT_HTTPHEADER] = $headers;
        curl_setopt_array($ch, $opts);
        $body = curl_exec($ch);
        if ($body === false) throw new RuntimeException(curl_error($ch));
        $status = (int) curl_getinfo($ch, CURLINFO_RESPONSE_CODE);
        curl_close($ch);
        return ['status' => $status, 'body' => $body];
    }

    public function get(string $path): array { return $this->request('GET', $path); }
    public function post(string $path, $fields = [], array $headers = []): array
    {
        return $this->request('POST', $path, is_array($fields) ? $fields : [], $headers);
    }
}

Logger

POST /api/logger/restart

Restart the Xray logging subsystem. No request body.

curl -X POST 'http://127.0.0.1:8080/api/logger/restart'
$xray = new XrayAPI();
$res  = $xray->post('/api/logger/restart');
200 OK
{"status":"ok"}

Statistics

GET /api/stats

Get a single stats counter. Optional reset after read.

QueryTypeDescription
namestringCounter name
resetbooltrue or 1 to reset after read
curl 'http://127.0.0.1:8080/api/stats?name=inbound>>>my-in>>>traffic>>>downlink'
$res = $xray->get('/api/stats?name=inbound>>>my-in>>>traffic>>>downlink');
200 OK
{"stat":{"name":"inbound>>>my-in>>>traffic>>>downlink","value":12345}}
GET /api/stats/query

Query counters by substring or auto-regex pattern. Use grouped=true for categorized output; groups are inferred from pattern (inbound>>>, user>>>, …) or set explicitly with group=inbound,user.

curl 'http://127.0.0.1:8080/api/stats/query?pattern=user>>>'
curl 'http://127.0.0.1:8080/api/stats/query?pattern=inbound>>>&grouped=true'
curl 'http://127.0.0.1:8080/api/stats/query?pattern=inbound>>>new-in>>>traffic>>>(uplink|downlink)&grouped=true'
200 OK flat: {"stat":[{"name":"...","value":100}]}
grouped: {"stats":{"inbound":{"vless-in":{"uplink":1024,"downlink":4096}}}}
GET /api/stats/sys

Runtime and memory statistics (goroutines, alloc, uptime, GC).

curl 'http://127.0.0.1:8080/api/stats/sys'
200 OK
{"uptime":3600,"numGoroutine":42,"alloc":...,"numGC":5}
GET /api/stats/online

Active session count for one user (?email=).

curl 'http://127.0.0.1:8080/api/stats/online?email=user@example.com'
200 OK
{"stat":{"name":"user>>>user@example.com>>>online","value":2}}
GET /api/stats/online/iplist

Source IPs for a user's active sessions.

curl 'http://127.0.0.1:8080/api/stats/online/iplist?email=user@example.com'
200 OK
{"name":"user>>>user@example.com>>>online","ips":{"1.2.3.4":1700000000}}
GET /api/stats/online/users

All users with at least one active session.

curl 'http://127.0.0.1:8080/api/stats/online/users'
200 OK
{"users":["user1@example.com","user2@example.com"]}
GET /api/stats/online/all

All online users with IPs in one call. Optional filter: ?email= (repeatable).

curl 'http://127.0.0.1:8080/api/stats/online/all'
curl 'http://127.0.0.1:8080/api/stats/online/all?email=u1@x.com&email=u2@x.com'
200 OK
{
  "users": [
    {"email": "user1@example.com", "ips": {"1.2.3.4": 1700000000}},
    {"email": "user2@example.com", "ips": {"10.0.0.1": 1700000002}}
  ]
}

Inbounds

POST /api/inbounds/add

Add one or more inbounds (Xray inbound JSON format).

{"inbounds":[{"tag":"new-in","protocol":"vless","listen":"0.0.0.0","port":8443,"settings":{"clients":[],"decryption":"none"}}]}
curl -X POST 'http://127.0.0.1:8080/api/inbounds/add' \
  -H 'Content-Type: application/json' \
  -d '{"inbounds":[{"tag":"new-in","protocol":"vless",...}]}'
200 OK {"status":"ok"}
POST /api/inbounds/edit

Replace existing inbound(s) by tag (runtime remove+add, config upsert). Tag must already exist.

{"inbounds":[{"tag":"vless-in","protocol":"vless","listen":"0.0.0.0","port":443,"settings":{"clients":[],"decryption":"none"}}]}
200 OK {"status":"ok"}
POST /api/inbounds/remove 
{"tags":["old-inbound"]}
200 OK {"status":"ok"}
GET /api/inbounds/list

List inbounds. ?tags_only=1 or ?isOnlyTags=true for tags only.

curl 'http://127.0.0.1:8080/api/inbounds/list'
curl 'http://127.0.0.1:8080/api/inbounds/list?tags_only=1'
200 OK
{"inbounds":[{"tag":"vless-in",...}]}

Inbound Users

POST /api/inbounds/users/add

Add users to existing inbound. Only tag + settings.clients required.

{"inbounds":[{"tag":"vless-in","settings":{"clients":[{"id":"uuid","email":"user@example.com"}]}}]}
200 OK {"added_users":1}
POST /api/inbounds/users/edit

Update existing users by email. Same body shape as add; emails must already exist.

{"inbounds":[{"tag":"vless-in","settings":{"clients":[{"id":"new-uuid","email":"user@example.com","flow":"xtls-rprx-vision"}]}}]}
200 OK {"updated_users":1}
POST /api/inbounds/users/remove 
{"tag":"vless-in","emails":["user@example.com"]}
200 OK {"removed_users":1}
GET /api/inbounds/users

?tag= required. Optional ?email= for one user.

curl 'http://127.0.0.1:8080/api/inbounds/users?tag=vless-in'
curl 'http://127.0.0.1:8080/api/inbounds/users?tag=vless-in&email=user@example.com'
200 OK
{"users":[{"email":"user@example.com",...}]}
GET /api/inbounds/users/count

?tag= required.

200 OK {"count":42}

Routing Rules

POST /api/rules/add

Add routing rules. Query: should_append=true to append (default false).

POST /api/rules/add?should_append=true

{"routing":{"rules":[{"type":"field","outboundTag":"direct","domain":["geosite:cn"]}]}}
200 OK {"status":"ok"}
POST /api/rules/edit

Replace one rule by rule_tag. Provide routing.rules (one rule) or a single rule object.

{"rule_tag":"my-rule","rule":{"type":"field","ruleTag":"my-rule","outboundTag":"direct","domain":["geosite:cn"]}}
200 OK {"status":"ok"}
POST /api/rules/remove 
{"ruleTags":["my-rule"]}
200 OK {"status":"ok"}
GET /api/rules/list 
200 OK
{"rules":[{"ruleTag":"...",...}]}

Balancer

GET /api/balancer/info

?tag= balancer tag.

200 OK
{"balancer":{...}}
POST /api/balancer/override 
{"tag":"balancer-1","target":"outbound-a"}
200 OK {"status":"ok"}
POST /api/sourceip/block

Block traffic by source IP via routing rule.

{
  "outbound": "blocked",
  "inbound": "socks",
  "rule_tag": "sourceIpBlock",
  "reset": false,
  "source_ips": ["1.2.3.4", "5.6.7.8"]
}
200 OK {"status":"ok"}

Config Import

POST /api/config/import

Write a config JSON file to disk. multipart/form-data only. Does not read runtime state.

FieldRequiredDescription
fileYesconfig.json file
pathNoTarget path; default = first startup config file
curl -X POST 'http://127.0.0.1:8080/api/config/import' \
  -F 'file=@/path/to/config.json' \
  -F 'path=/etc/xray/config.json'
$fields = [
  'file' => new CURLFile(__DIR__.'/config.json', 'application/json', 'config.json'),
  'path' => '/etc/xray/config.json',
];
$res = $xray->post('/api/config/import', $fields);
200 OK {"status":"ok","path":"/etc/xray/config.json"}
